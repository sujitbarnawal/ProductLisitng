# Product Listing Webpage

This project is a **simple product listing webpage** built using **React**. It demonstrates fundamental frontend concepts such as **API fetching, searching, filtering, infinite scrolling**, and **responsive UI design**.

---

## Features

- **Products page** with product list fetched from a dummy API  
- **Search bar** to filter products by name  
- **Category filter dropdown**  
- **Infinite scroll** to load more products dynamically  
- **Fully responsive design** for desktop, tablet, and mobile  
- **Add to cart**

---

## Tech Stack

- **React** (with React Router for navigation if needed)  
- **Tailwind CSS** for styling  
- **Axios** for API requests  
- **Dummy API** (`https://dummyjson.com/products`) for products
